# Python Exercises

An archive of exercises, small programs, and notes from my early Python studies, based on *Head First Python*. This is learning material, not a maintained software package.

## Contents

- Beginner exercises and examples covering Python fundamentals
- Small scripts and examples from the course
- Text files and sample audio assets used by some exercises

The original flat layout is retained so existing scripts can continue to find their companion files. Run scripts from the repository root when they use relative file paths.

## Notes

- Some examples are old and may need updates for current Python versions.
- There is no shared dependency file or automated test suite; requirements may vary by script.
- Please check the source and license of bundled audio assets before reusing or redistributing them. This repository does not include a project-level license.
- Python bytecode, virtual environments, and local IDE files are excluded with `.gitignore`.

This repository documents my learning journey. My more recent projects are highlighted on my [GitHub profile](https://github.com/carloscesar182).
